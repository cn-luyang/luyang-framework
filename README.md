一个基于 Spring Boot 的项目脚手架，当前处于初步搭建阶段。

这个项目主要用于自我练习，梳理常用模块、组件拆分思路，希望在构建过程中不断加深对工程结构和代码设计的理解，也欢迎感兴趣的朋友一起交流学习。

---

## 💡 Why 自己造轮子？
> 学习工程拆分思维，  
> 梳理一套自己的开发习惯，  
> 在动手中发现细节，沉淀技术。

做过不少业务项目后，发现很多代码和结构都可以沉淀下来形成共用模块。虽然网上已有很多轮子，但自己动手搭一个，能学到更多设计细节，也能更好地服务后续项目开发。

---

## 🎯 项目目标

- 提供一个结构清晰、职责分明的脚手架模板
- 支持模块化引入和定制
- 保持代码风格简洁、命名优雅
- 更重要的是：边写边学，不断完善 🧱

---

## 🧩 模块说明

> 项目还在搭建阶段 🚀 快速开始（开发中）

| 模块名称                          | 简要说明                           |
|-----------------------------------|------------------------------------|
| `luyang-framework-starter-base`     | 通用基础配置（全局异常、统一返回体） |
| `luyang-framework-starter-web`      | Web 配置（跨域、日志、接口规范等）   |
| `luyang-framework-starter-security` | 安全认证封装（待扩展）               |
| `luyang-framework-starter-redisson` | 分布式 Redis 工具（锁、限流等）     |
| `luyang-framework-base-util`        | 通用工具类                         |
| `luyang-framework-base-wrap`        | 响应包装、枚举处理等                 |
