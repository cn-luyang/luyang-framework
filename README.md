## 🌟 这是一个什么样的项目？

LUYANG-FRAMEWORK 是我在利用所有碎片时间，完全出于兴趣和热爱打造的一套现代 Java 后端脚手架。

它没有宏大的商业目标，也没有和任何成熟框架竞争的野心。

它只是：

- 我这几年踩过的坑、抄过的轮子、熬过的夜的集大成者
- 我把社区里无数优秀实现“抄”到手抽筋后，再用自己的方式重新写一遍的成果
- 我对自己代码审美、工程习惯、技术深度的一次系统性输出
- 一个永远在施工中的“个人技术宫殿”

**写给未来的自己，也写给每一个和我一样爱折腾、爱钻研、爱写优雅代码的后端程序员。**

---

## ⚡ 你能在这里收获什么？

| 功能领域                  | 具体能力点                                                                                                 |
|-------------------------|----------------------------------------------------------------------------------------------------------|
| 🎁 统一响应 & 全局异常      | 美观的 Result、分层错误码、国际化提示、详细堆栈（dev 模式）                                                    |
| 🌍 Web 层增强             | 请求响应日志、幂等防重、参数脱敏、XSS 防御、统一分页、全局跨域                                                    |
| 🗃️ MyBatis Plus 增强      | 动态多租户、字段加密、数据权限、自动填充优化、自定义代码生成                                                    |
| 🔒 Redisson 极简工具链     | 一行代码分布式锁（支持红锁/读写锁）、限流、分布式集合、自动续期、失败策略                                         |
| 🏷️ 字典 & 枚举翻译         | @Dict 注解一键翻译、字典缓存自动刷新、前端枚举同步、下拉/标签/颜色                                              |
| 🔐 安全认证体系            | Spring Security + JWT 无感刷新 + 动态权限 + 登录日志 + 密码策略                                               |
| 🧰 实用工具集合            | 分布式 ID、对象复制、脱敏工具、Excel 增强、Flyway 管理、优雅关机、动态配置热加载等                                |

**所有功能都是独立 Starter，未实现的还在逐步完成**

## ❤️ 为什么还要自己造轮子？

- 🧠 只有亲手写一遍才算真正理解
- ✍️ 我享受那种“只属于我一个人的专注感
- 🎨 100% 符合我的代码审美 —— 命名、结构、异常处理，全都我说了算
- ⚡ 以后新项目直接 git clone 就能起飞，再也不从零搭环境
- 🔥 最重要的是：一个普通打工人，凭兴趣和坚持，也能把事情做到极致
